```

```

### Pause Between Commands
```
1. Say a command
2. Wait 2-3 seconds
3. Listen for feedback
4. Say next command
```

## ❓ Common Questions

**Q: How do I enable voice?**
A: Click the "Listen" button in the bottom-left corner

**Q: What if command isn't recognized?**
A: Say "help" to get suggestions or speak more clearly

**Q: Can I use short names?**
A: Yes! "Trinity" works for "Trinity College Dublin"

**Q: How do I fill forms?**
A: Say: "fill [fieldname] with [value]"

**Q: How do I submit?**
A: Say: "submit form" or "click submit"

**Q: Can I scroll by voice?**
A: Yes! Say "scroll down" or "scroll up"

**Q: Can I read page content?**
A: Yes! Say "read page" or "read heading"
