# Central Application Platform

## Project Overview

A **production-ready, full-stack admissions management platform** serving educational institutions and recruitment agencies across South Africa. This enterprise-grade application handles 700+ programmes from 20+ institutions with complete accessibility compliance and voice-first user experience.

## Technical Highlights

### Architecture & Scale
- **Backend:** Node.js/Express with MongoDB - handling 5000+ database records
- **Frontend:** React 18+ with Vite - optimized bundle size (~150KB gzipped)
- **Full-Stack:** Complete end-to-end development from database to UI
- **API Design:** RESTful endpoints with authentication, caching, and error handling

### Advanced Features Built
✅ **Voice-First Interface** - Web Speech API integration with <200ms latency  
✅ **WCAG 2.1 AA Accessibility** - Full compliance for screen readers and keyboard navigation  
✅ **Real-time Search** - Instant filtering across 700+ programmes with intelligent ranking  
✅ **User Management** - JWT authentication, role-based access, secure sessions  
✅ **Data Export** - CSV/JSON export with bulk processing capabilities  
✅ **Responsive Design** - Mobile-first approach working on all devices  
✅ **Performance Optimized** - Caching strategies, lazy loading, optimized queries

## Getting Started (For Recruiters)

1. Clone the repository
2. Install dependencies: `npm install` (both frontend and backend)
3. Start servers: `npm run dev` (backend) and `npm run dev` (frontend)
4. Visit http://localhost:3001
5. Explore institutions, test voice commands, and review the codebase
