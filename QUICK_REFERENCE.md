## 🚀 Quick Start (30 seconds)

### Path 1: "I want to explore"
```
Click "Browse Courses" 
  → Search or filter
  → Click course checkboxes (up to 10)
  → Click "Apply Now"
  → Done!
```

### Path 2: "I know my APS"
```
Click "Smart Recommendations"
  → Enter your Total APS, Math APS, English APS
  → See Excellent/Good/Borderline matches
  → Select courses you like
  → Click "Apply to Selected Recommendations"
  → Done!
```

### Path 3: "I applied, now what?"
```
Click "Track Status" (must login)
  → See all your applications
  → Filter by Accepted/Pending/Rejected
  → Read status reason
  → Follow next steps
  → If rejected → Click "Get Smart Recommendations"
```

## 🎯 APS Score Guide

### What is APS?
Admission Point Score - numerical representation of your matric results

### The Numbers:
```
TOTAL APS: 0-100 scale
Most courses need: 20-50 points
Higher = better

MATH APS: 0-7 scale
7 = Excellent
4 = Good
2 = Minimum for most courses

ENGLISH APS: 0-7 scale
Same as Math
English proficiency is required
```

### Example Students:

**Student A:**
```
Total: 70 (excellent)
Math: 6 (very good)
English: 6 (very good)
Result: Can apply to top universities ✓✓✓
```

**Student B:**
```
Total: 35 (average)
Math: 2 (basic)
English: 3 (decent)
Result: Medium difficulty courses ✓✓
```

**Student C:**
```
Total: 18 (below average)
Math: 0 (didn't take)
English: 1 (poor)
Result: Few options, limited choices
```

## ❓ FAQ

**Q: How many courses can I apply to?**
A: Up to 10 per submission. After getting responses, you can apply to more.

**Q: Do I need login to browse courses?**
A: No! You can browse universities, courses, and get recommendations without login.

**Q: Do I need login to apply?**
A: Yes. You need an account to submit applications.

**Q: What if I don't know my APS?**
A: You can upload your matric certificate, or manually check your results and enter the scores.

**Q: Can I change my application after submitting?**
A: No, but you can apply to more courses separately.

**Q: What if I get rejected from all 10?**
A: Click "Get Smart Recommendations" to see better-matched courses, then apply to a new batch.

**Q: How long until I get a response?**
A: Typically 2-3 weeks. You can track status on Track Status page.

**Q: Can I apply to the same course twice?**
A: No, the system prevents duplicate selections.

**Q: What does "Borderline" mean?**
A: You're 0-3 APS points below the minimum. You can still apply but acceptance is uncertain.

**Q: Should I apply to Borderline courses?**
A: Yes, if you're strategic. Include some borderline as "reach" courses among safer bets.
