# CAO Handbook - Quick User Guide

## Welcome to the CAO Handbook! 📚

This page helps you find all 719 CAO courses from 21 South African universities.

---

## Getting Started in 3 Steps

### Step 1: Search for a Course 🔍
1. Click in the search box at the top
2. Type what you're looking for:
   - **By course code:** Type "ZU-M-BAS"
   - **By course name:** Type "accounting" or "nursing"
   - **By school:** Type the university name
3. Results appear instantly as you type

**💡 Example searches:**
- "B Accounting" (finds all accounting degrees)
- "UP" (finds all UP courses)
- "Engineering" (finds all engineering programmes)

---

### Step 2: Pick Your School 🏫
1. Click the "Which school?" dropdown
2. Select one school or leave it as "All Schools"
3. See how many courses each school has in brackets
4. The list updates instantly

**Example:**
- "University of Pretoria (45 courses)"

---

### Step 3: Save Courses You Like ⭐
1. Click the checkbox next to any course you like
2. See your count increase in "Your Picks" button
3. Click "Your Picks" to show only saved courses
4. Download your list as Excel or Data file

---

## How to Search

### Search Box 🔍
**"What course are you looking for?"**

**You can search by:**
- Programme code (e.g., "ZU-M-BAS")
- Programme name (e.g., "nursing")
- Institution (e.g., "Wits")

**💡 Tips:**
- Type slowly to see results appear instantly
- You don't need to spell perfectly - try typing just part of the word
- Searching is case-insensitive (uppercase and lowercase both work)

### Filter by School 🏫
**"Which school?"**

- Pick one school from the dropdown
- Or leave as "All Schools" to see everything
- Number in brackets shows how many courses each school has
- Example: "University of Johannesburg (38 courses)"

### Your Picks ⭐
**"Your Picks"**

- Checkbox on left side of each course = save it
- Button shows how many you've saved
- Click the button to show ONLY your saved courses
- Click again to show everything

---

## How to View Courses

### Click to Expand
1. Find a school name (e.g., "🏫 University of Pretoria")
2. Click anywhere on the blue header
3. All courses from that school expand down
4. Click again to collapse (hide) them

### Understanding the Course Card

```
☐ ZU-M-BAS  ✓ Official
  Bachelor of Accounting (Accounting)
  📄 Page: 123
```

- **☐** = Checkbox to save this course
- **ZU-M-BAS** = Course code (official code from CAO)
- **✓ Official** = Verified by CAO as official
- **Programme Name** = Full name of the course
- **📄 Page: 123** = Where to find it in the handbook

### Handbook Page

## Tips & Tricks

### Finding Your Course
1. **Know the university?** Use the school filter first
2. **Know the course name?** Search for it (e.g., "law")
3. **Have the CAO code?** Type the code (e.g., "UP-B-LAW")
4. **Not sure?** Try searching with partial words

### Saving Courses
1. **Save as you browse** - Click checkboxes while looking
2. **Save by school** - Click the big checkbox at top to save all from one school
3. **Review your list** - Click "Your Picks" to see what you saved
4. **Change your mind?** - Click checkbox again to unsave

### If No Results Found
- Check spelling (typos don't work)
- Try a shorter search (just "account" instead of "accounting")
- Try without numbers
- Try the school filter instead
- Click "Clear Filters & See All" to start over
