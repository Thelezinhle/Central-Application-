# 🏫 University Voice Commands - Quick Start

## Essential Commands

### See All Universities
```
"show all universities"
"list universities"
```

### Apply to University
```
"apply to Trinity"
"apply to University College Dublin"
"apply to Cork"
```

### Get University Information
```
"tell me about Trinity"
"tell me about UCD"
"show university details for Trinity"
```

### Find by Location
```
"universities in Dublin"
"universities in Cork"
"universities in Limerick"
```

### Compare Universities
```
"compare Trinity and UCD"
"compare Trinity and Cork"
```

---

## Step-by-Step Workflow

### Quick Apply Process
```
1. "apply to Trinity"
   → Application form opens with Trinity pre-selected

2. "fill firstName with John"
   → Your name is entered

3. "fill email with john@example.com"
   → Your email is entered

4. "submit form"
   → Application submitted
```

### Research Then Apply
```
1. "universities in Dublin"
   → See Dublin universities

2. "tell me about Trinity"
   → Get Trinity details

3. "tell me about UCD"
   → Get UCD details

4. "compare Trinity and UCD"
   → See comparison

5. "apply to Trinity"
   → Apply to Trinity
```

### Explore Multiple Universities
```
1. "show all universities"
   → See all 30+ universities

2. "scroll down" (if needed)
   → See more options

3. "universities in [location]"
   → Filter by location

4. "apply to [university]"
   → Apply to your choice
```

## Tips for Best Results

✅ **Be Specific:** Use full or common short names
✅ **Take Time:** Pause between commands (2 seconds)
✅ **Speak Clearly:** Enunciate university names
✅ **Listen First:** Ask about university before applying
✅ **Fill Completely:** Make sure all fields are filled
✅ **Confirm:** Listen for confirmation after each action

## Troubleshooting

**Can't find university?**
- Say: "show all universities"
- Check exact name
- Try shorter name (Trinity not Trinity College Dublin)

**Need more info?**
- Say: "tell me about [name]"
- Say: "show university details for [name]"
- Say: "universities in [location]"

**Application issue?**
- Say: "read page" to hear errors
- Fill missing fields
- Try submit again
