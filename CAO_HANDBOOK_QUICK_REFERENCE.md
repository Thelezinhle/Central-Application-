## 💡 Tips & Tricks

**Search Tips:**
- Don't need exact spelling (fuzzy match works)
- Try partial words: `acc` for accounting
- Case doesn't matter: `CAO` = `cao`
- Search by any part: code, name, or university

**Filter Tips:**
- Filter by school first = faster searching
- Use "Your Picks" to compare options
- Save everything and download later
- Checkboxes don't lose data if page reloads

**Download Tips:**
- Excel = spreadsheet (use in Excel/Sheets)
- JSON = data file (use with code/apps)
- Downloads only what you're viewing
- Save file and share with friends
